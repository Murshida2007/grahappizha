## 📝 Project Description

**ഗ്രഹപ്പിഴ.com** is a humorous Malayalam astrology-themed website designed to give users an entertaining horoscope experience.

Users can enter their name, nakshatram, date of birth, birth time, and current life crisis. They can also capture a photo using their device camera and proceed through a multi-page horoscope journey featuring Malayalam content, traditional astrology-inspired visuals, background decorations, audio effects, and a personalized result page.

# 🛠️ Technical Details

## Technologies / Components Used

### For Software

- **HTML5** — Website structure and page layouts
- **CSS3** — Responsive design, animations, gradients, decorative elements, and styling
- **JavaScript** — Form validation, camera access, photo capture, local storage, page navigation, audio effects, and dynamic result display
- **Web APIs**
  - `getUserMedia()` for live camera access
  - `Canvas API` for capturing photos
  - `localStorage` for saving user details and captured images
  - `Audio API` for sound effects
- **Google Fonts**
  - Baloo Bhai 2
  - Noto Sans Malayalam
  - Poppins
- **GitHub** — Source code hosting and project documentation
- **Visual Studio Code** — Development environment
- **Git / GitHub** — Version control and collaboration

### For Hardware

- Smartphone, tablet, or computer
- Device camera
- Internet connection
- Web browser
- Keyboard and mouse, if using a computer
